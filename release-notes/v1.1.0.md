# RainPointClient 1.1.0

Adds assigned zone names and typed home-configuration notifications, scoped to the signed-in account and monitored home. Account MQTT registration uses the private account identity returned at sign-in and preserves it across token refresh.

Adds optional suppression of routine status polling while synchronized MQTT is available. Existing applications retain periodic polling by default. Startup, reconnect catch-up, fallback polling and manual refresh remain supported. `LiveUpdatesAvailable` describes observer synchronization, not physical device freshness.

Development tests now use NUnit 5. The public client remains C# 14 targeting .NET Framework 4.7.2 and .NET 10.
