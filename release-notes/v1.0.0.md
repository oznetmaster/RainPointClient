# RainPointClient 1.0.0

First release of the pure C# RainPoint Home / Smart+ cloud client, targeting **.NET Framework 4.7.2** and **.NET 10**. It supports the **HWG023WBRF / HWG023WBRF-V2 hub** with the **HTV345FRF three-zone RF timer**.

## Included

- All-zone normal irrigation, misting and cycle-and-soak, typed status/usage and MQTT feedback with polling fallback.
- Saved plans, five supported writable recurrence forms, volume limits, seasonal settings, rain delay and home-timezone-aware calendar projections.
- Usage/event history, zone profiles, account/home/room/member administration, supported Smart Scenes and execution history.
- A Windows workbench for both runtime targets, with encrypted optional credential storage and automatic startup sign-in.
- Attributed System.Text.Json transport models and typed public APIs.

## Validation

The desktop baseline passed **2,878 tests**: 1,352 library/dashboard and 87 WPF tests on each target. NUnit 4.6.1, NUnit3TestAdapter 6.3.0, Microsoft.NET.Test.Sdk 18.10.1 and NUnit.Analyzers 4.15.0 are development dependencies only.

Short live checks verified all-zone normal feedback, zone-1 misting/cycle delivery feedback, schedule recurrences, seasonal scaling, rain-delay suppression/resumption, a volume cutoff, simultaneous shared accounts, scene-history pagination and account/membership restoration. The even-day run observed execution but failed a cleanup read; separate cleanup-only recovery succeeded. Original failures remain retained. See the [test guide](https://github.com/oznetmaster/RainPointClient/blob/v1.0.0/tests/README.md) and [validation ledger](https://github.com/oznetmaster/RainPointClient/blob/v1.0.0/docs/TODO.md).

## Scope

This release uses the RainPoint cloud. Local-protocol research is independent and does not block this release. Additional device families, sensor-dependent execution, natural long-term session expiry and initial provisioning are not claimed as validated. Historical Once plans remain readable/removable, but cannot be created/enabled on this timer. Reported usage is not an independently calibrated physical measurement.

## Install and assets

```powershell
dotnet add package RainPointClient --version 1.0.0
```

The NuGet package contains both target assemblies, XML API documentation, README, license, notices, changelog and these notes. GitHub assets additionally provide target-named DLL/XML files, framework-dependent Windows ZIPs and a SHA-256 manifest. The Windows net472 ZIP requires .NET Framework 4.7.2 or later; the modern ZIP requires the .NET 10 Desktop Runtime. Extract each ZIP into its own folder before running the app.

Read the [README](https://github.com/oznetmaster/RainPointClient/blob/v1.0.0/README.md) for usage and links to the feature guides.
