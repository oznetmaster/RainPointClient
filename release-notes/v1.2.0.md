# RainPointClient 1.2.0

Adds HTV145FRF one-zone and HTV245FRF two-zone RF timer handling alongside HTV345FRF. The added scope includes discovery, normal timed start/stop, HTTP and MQTT status decoding, assigned zone names and per-zone saved-plan reads. Compact single-zone status framing is decoded structurally and malformed records are rejected.

The vendor app shares per-zone controls and plan handling across port counts. Reference captures and offline NUnit fixtures cover the added models; no physical HTV145FRF/HTV245FRF hardware was tested. Manual cycle/misting and advanced configuration writes retain the existing HTV345FRF restrictions. Missing readings remain unknown and command acceptance remains separate from reported activity.

Targets .NET Framework 4.7.2 and .NET 10 with C# 14. The offline suite passes 1,399 library/dashboard cases and 87 Windows app cases on each target, 2,972 total. See [variant evidence](https://github.com/oznetmaster/RainPointClient/blob/v1.2.0/docs/TIMER-VARIANTS.md) and the [test guide](https://github.com/oznetmaster/RainPointClient/blob/v1.2.0/tests/README.md).
